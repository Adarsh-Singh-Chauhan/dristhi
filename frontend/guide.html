01 · USER LOGIN◎

Use the DRISHTI workspace

  1. Open the main workspace and choose Sign in.
  2. New users can select Create an account; use an email and a strong password.
  3. Paste a message or public claim you are authorised to review. Choose the platform and submit it.
  4. Read the matched signals, explanation and verification checklist. The score is review priority, not a truth percentage.
  5. Sign in to save report history. You can review and delete your own saved reports.
Go to user workspace ↗
02 · ALERTS & SOS⚑

Manage safety alerts

  1. Sign in on the Alerts & SOS page using your normal user account.
  2. Add trusted contacts you may want to reference in a request.
  3. For an urgent review request, enter the incident title, details and optional source URL.
  4. Choose whether to share your current GPS location. The browser asks for permission only when you submit.
  5. Your SOS goes to the DRISHTI Superadmin review queue. No SMS, WhatsApp, police or emergency-service dispatch is sent automatically.

GPS is a one-time location snapshot for that SOS only. Untick the option to submit without coordinates.

03 · SUPERADMIN▣

Operate the control room

  1. Register your intended Superadmin email once through the normal user registration flow.
  2. Connect the dedicated PostgreSQL database and run the migration in the repository.
  3. Run scripts/promote_first_admin.py locally with the private database connection string to promote that registered account.
  4. Open the separate Superadmin page and sign in with that email and the password you chose.
  5. Review evidence case files, require a source summary before a conclusion, then inspect SOS reports, optional shared coordinates, network indicators, users, audit events and in-app notices.

The bootstrap is single-Superadmin and refuses to promote a second administrator. Never put credentials or database secrets in GitHub.

04 · CYBER / NETWORK⌁

Investigate network indicators

  1. Use the IOC register only for public IP addresses or domains from a source your organisation is authorised to inspect.
  2. Record the evidence reference, severity and a short analyst note.
  3. Country, city and map coordinates are optional analyst-supplied GeoIP estimates. They are not precise device locations.
  4. Review the indicator and mark it under review, confirmed or false positive.
  5. Every create/status action is recorded in the Superadmin audit trail.

DRISHTI does not capture website visitors' IPs, identify the person behind an IP, scan private networks or provide live location tracking.

05 · MOBILE APP▤

Install DRISHTI on your phone

  1. Open the live HTTPS website in Chrome on Android or Safari on iPhone.
  2. On Android, tap Install app or browser menu → Install app / Add to Home screen.
  3. On iPhone, tap Share → Add to Home Screen.
  4. Launch DRISHTI from its home-screen icon. The app shell can open offline; analysis and account actions still require the API.

This is an installable Progressive Web App (PWA), not a Play Store APK or native iOS package.

06 · PRIVACY & LIMITS✳

Know what the map can show

  • User GPS: shown only when the user explicitly shares it for a particular SOS.
  • IP geolocation: approximate network region only; it can be wrong, especially for VPNs, proxies and mobile carriers.
  • Global map: displays saved snapshots and analyst-entered IOC coordinates, not live movement.
  • Analysis: current engine is an explainable rule-based prototype, not a trained fact-checking model.
  • Emergency help: DRISHTI SOS is an internal review request, not an emergency dispatch service.
FIRST-TIME SETUP

Accounts need persistent storage.

The live API can run anonymous analysis without a database. User registration, login, saved history, case files, SOS, Superadmin and network IOC persistence require the private PostgreSQL DATABASE_URL described in docs/SUPABASE-FREE-SETUP.md. Do not enter secrets into this website or commit them to source control.
